## Context
ADR-001: one inference, two output layers. GM v2 = `gm_core` (pure frame → rows, numerically identical to v1) +
`gm_context` (incremental per-video decisions with `decided_at`) + sinks (v2 bus through `pf.contract`/`pf.receiver`,
v1-compat second-run file for the 27 modules). Source facts: `docs/analysis/gm_current.md`, `module_consumption.md`,
`contract_observed.md`.
