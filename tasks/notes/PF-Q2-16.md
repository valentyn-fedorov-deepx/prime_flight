# PF-Q2-16 · A production GM baseline for the monthly test

- **Owner:** Maksym Ch. (the run on the cluster) + Oksana (scoring) · **Agent:** qa-parity · **Status:** todo (requested 2026-10-20)
- **Why:** `docs/analysis/gm_baseline_lineage.md` — the monthly test compares against GM 087dfa9 (April 2024, BGR heads);
  production (`deployment_v_py3_10`: code a0157a4, image d4ae8e5, RGB heads) has GM files for 1 of the 90 test videos, so
  its module accuracy has never been measured on the monthly set, and every GM change is judged against the wrong model.

## Steps

1. **Run production on the 90 videos.** `deployment_v_py3_10` @ d4ae8e5, in the same image as the `afaebf1` run of
   2026-10-15/16 (same node type), the usual job (`--write_video` as in that run). Files land as
   `gs://cv-modules-topics/<video>/general_modeld4ae8e5.ndjson`.
2. **Check the optimised branch against it.** `general_modelafaebf1.ndjson` vs `general_modeld4ae8e5.ndjson` per video:
   expected byte-identical in one image (`tasks/notes/PF-Q4-02.md`: three full-event A/B runs on one machine, every output
   identical). On Bdx1iGrXPEfe the two cluster runs of 13.10 (a0157a4) and 15.10 (afaebf1) agree on 99.95 % of the
   detection pairs, 99.5 % within ±2 px / ±0.02 — the level two different images or GPUs give; which image each run used
   is the first thing to confirm.
3. **Trackers and modules on the d4ae8e5 files, scored against the labels** — the first measurement of the production
   GM. Per task, compare with the April-2024 scores; the CSV of 2026-10-17 (`gm-files-for-score-drop.csv`) shows drops on
   56 of 90 videos, worst on safety huddle, pre-departure walk-around, pin verification, handrails on GSE, cones removed,
   steering, hand signals, safety zone.
4. **Point the monthly test's GM baseline at the production branch head**, so it moves when production does.

## Acceptance

- d4ae8e5 files for all 90 videos; afaebf1 identical to them (or every difference explained by the image).
- Module scores of the production GM on the 90 videos, per task, next to the April-2024 ones.
- The monthly test configured with the production branch as its GM baseline.
