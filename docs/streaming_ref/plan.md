# План перенесення на стрімінг — один цикл

Повна версія з таблицями: [plan.html](plan.html) · [plan.png](plan.png)

## Критерії готовності
| # | критерій | стан |
|---|---|---|
| D1 | чанкова подача = наскрізна, побітово | виконано |
| D2 | прод-код 4 перевірок у стрім-режимі | виконано |
| D3 | стейдж-детектор віддає T_arr / T_dep / BL@door / BL leave причинно; модулі гейтовані по стадіях | план |
| D4 | різниця вердиктів пакет ↔ стрім виміряна для кожної з 4 | 2 з 4 |
| D5 | зсув якоря Nose wheel ≤ 24 с або задокументований | план |
| D6 | CI: швидкі гейти + нічний прогін на GPU-раннері | гейти є, раннера нема |
| D7 | чесний звіт | план |

**Не рахуємо доставленим:** pushback-pathway, поки повнота 0 з 4.

## Критичний шлях
K1 контракт v1.0 → K2 приймач + реєстр сесій → K3 детектор v0 (T_arr, T_dep, BL@door, BL leave)
→ K4 pushback_attached причинно → K5 гейтування → K6 хвиля 1 через детектор → K7 звіт.

Детектор раніше за модулі: 9 модулів перераховують arrival stage самі, 2 — pushback_attached.
Перенесення без детектора означає чіпати їх двічі.

## Паралельно
- **Заміри/розмітка:** fail-и для Nose wheel (1 на 90); Main gear на всіх 30 fail; чиста вартість
  на кадр для 9 піксельних; втрата чанка fill/shift; повнота pushback-pathway (вікно 45 с, класи).
- **Поза нашою зоною — запитати на тижні 1:** GPU-раннер, аплінк, VPN, інтерфейс до шини алертів.
- **Гігієна:** schema_version у trackers + тест витікання полів; реєстр (crew-present full_name,
  seat-belts у розкладці, aircraft/jet); dead model у wing-walkers; чужий model_name у `__main__`; gzip.

## Черга після четвірки
2а — 8 легких на dd5b554 в одному процесі (лише за наявності fail-розмітки) · 2б — bl_rear_cone,
3-stop, cones-are-removed · 3а — піксельні без своїх мереж · 3б — з мережами (vests останні) ·
4 — двопрохідні (pin-verification патч; safety-zone, hand-signals — геометрія з буфера) ·
walk-around — пост-обробка.

## Тижні
1 рішення, контракт, каркас приймача, детектор v0, запити назовні, гігієна, замовити розмітку ·
2 pushback_attached, гейтування, замір вартості на кадр, Main gear на 30 fail ·
3 хвиля 1 через детектор, розбіжності, втрата чанка, pushback-pathway ·
4 nightly (якщо раннер), звіт, пробний прогін 2а.
